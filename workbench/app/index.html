Mobile Trust Store Installation Guide
  1. Download the .crt certificate using the button below.
  2. Open Android Settings ➔ Security & Privacy ➔ More Security Settings.
  3. Tap Encryption & Credentials ➔ Install a Certificate ➔ CA Certificate.
  4. Select the downloaded nexusproxy-ca.crt and tap Install Anyway.
  1. Download the .mobileconfig profile below in Safari.
  2. Go to Settings ➔ Profile Downloaded ➔ Install.
  3. Go to Settings ➔ General ➔ About ➔ Certificate Trust Settings.
  4. Under "Enable full trust for root certificates", toggle NexusProxy Testing Root CA ON.
